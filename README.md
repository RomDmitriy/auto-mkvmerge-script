Соединение видео, аудио и субтитров в один mkv файл.

Требование к файлам: каждый файл типа (видео, аудио, субтитры) должен иметь идентичное название, которое отличается лишь номером эпизода. Если файл единственный (например, фильм) - добавляем в название "01" и запускаем скрипт с параметрами (1 и 1).

## Иструкция

### Windows

1. Поменять пути к файлам в скрипте (переменные подписаны). Вместо номера серий подставить "$number" (без кавычек).
2. Если надо, поменять параметры сборки (всё подписано)
3. Запустить скрипт в папке с mkvmerge.exe

### macOS / Linux

1. Поменять пути к файлам в скрипте (переменные подписаны). Вместо номера серий подставить "$number" (без кавычек)
2. Если надо, поменять параметры сборки (всё подписано) и, при необходимости, путь до mkvmerge. Указанный путь работает "из коробки", если mkvtoolnix установлен через пакетный менеджер (например, homebrew)
3. Запустить `script.sh` с параметрами первого и последнего эпизода (например, `sh ./script.sh 1 12`)
